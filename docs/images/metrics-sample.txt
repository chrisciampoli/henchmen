# Sample output of GET /metrics/prometheus (Mastermind)
#
# Rendered by the real metrics router (henchmen.observability.api) over a
# 7-day window holding three tasks: two bugfix_standard runs that opened PRs
# with passing CI, and one feature_standard run that escalated before CI.
# The values are illustrative; the metric names, types and labels are exactly
# what the endpoint emits.
#
# Every series is a gauge recomputed from the trailing ?days= window (default
# 7) on each scrape, labelled window_days. henchmen_ci_pass_rate is omitted
# entirely until at least one CI result has landed in the window.
#
# Reproduce against a running stack (requires `pip install -e ".[observability]"`;
# the endpoint returns 503 without prometheus-client):
#
#   curl -s -H "Authorization: Bearer $HENCHMEN_METRICS_AUTH_TOKEN" \
#     "http://localhost:8000/mastermind/metrics/prometheus?days=7"

# HELP henchmen_tasks_completed_window Tasks that reached a successful terminal state within the window.
# TYPE henchmen_tasks_completed_window gauge
henchmen_tasks_completed_window{window_days="7"} 2.0
# HELP henchmen_tasks_escalated_window Tasks that escalated within the window.
# TYPE henchmen_tasks_escalated_window gauge
henchmen_tasks_escalated_window{window_days="7"} 1.0
# HELP henchmen_cost_usd_window Total estimated LLM spend (USD) over the window.
# TYPE henchmen_cost_usd_window gauge
henchmen_cost_usd_window{window_days="7"} 1.66
# HELP henchmen_ci_pass_rate Fraction of decided CI runs that passed. Absent when no data.
# TYPE henchmen_ci_pass_rate gauge
henchmen_ci_pass_rate{window_days="7"} 1.0
